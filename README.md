# ToDo List CLI

[![Go version](https://img.shields.io/github/go-mod/go-version/itsabyr/todo-cli)](go.mod)
[![License](https://img.shields.io/github/license/itsabyr/todo-cli)](LICENSE)

Консольное приложение «Список дел» на Go, работающее с пользовательским вводом. Учебный проект для закрепления материала первой части [полного курса по Golang](https://www.youtube.com/watch?v=dpvRDJjUJf8).

> **Важно.** Цель проекта — повторение пройденного материала, а не демонстрация лучших практик. Многие подходящие для этой задачи инструменты и приёмы намеренно не использовались. Просьба учитывать это при оценке исходного кода.

## Возможности

### Задачи

- Добавление новых задач
- Просмотр полного списка задач
- Отметка задачи как выполненной (по заголовку)
- Удаление задачи (по заголовку)

Каждая задача содержит:

| Поле | Описание |
|------|----------|
| Заголовок | Одно слово, используется как идентификатор |
| Текст | Произвольное количество слов |
| Время создания | Фиксируется при добавлении |
| Статус | Выполнена / не выполнена |
| Время выполнения | Фиксируется при отметке задачи выполненной |

Все задачи хранятся в памяти программы на протяжении её работы.

### События

Событием считается каждый пользовательский ввод. Для каждого события сохраняются:

- текст пользовательского ввода;
- описание: текст ошибки, если ввод завершился ошибкой, иначе пустая строка;
- время создания события.

Список всех событий за время работы программы доступен через команду `events`.

## Команды

| Команда | Формат | Описание |
|---------|--------|----------|
| `help` | `help` | Показать доступные команды и их формат |
| `add` | `add {заголовок} {текст задачи}` | Добавить задачу. Заголовок — одно слово, текст — одно или несколько слов |
| `list` | `list` | Вывести список всех задач |
| `done` | `done {заголовок}` | Отметить существующую задачу как выполненную |
| `del` | `del {заголовок}` | Удалить задачу по заголовку |
| `events` | `events` | Вывести список всех событий |
| `exit` | `exit` | Завершить работу программы |

### Пример использования

```text
> add shopping Купить молоко и хлеб
> list
> done shopping
> del shopping
> events
> exit
```

## Технические детали

- Оформлено как Go-модуль: `github.com/itsabyr/todo-cli`
- Помимо пакета `main`, содержит дополнительные пакеты
- Использует стороннюю библиотеку [`github.com/k0kubun/pp`](https://github.com/k0kubun/pp) для форматированного вывода

## Запуск

Требуется установленный [Go](https://go.dev/dl/).

```bash
git clone https://github.com/itsabyr/todo-cli.git
cd todo-cli
go run .
```
